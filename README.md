# Web doplňku IC Office Tutoriál 2

Statický web doplňku — zásady soukromí, obsah ke stažení a balíčky.
Běží na GitHub Pages pod adresou **https://tutorial.mujautoservis.eu/**.

**Needitovat ručně.** Obsah se generuje v privátním repozitáři
`ic-office-pruvodce-v2` příkazem `node build/web.mjs` a sem se jen kopíruje
(`build/publikuj-web.ps1` tamtéž). Ruční zásah přepíše první další publikace.
